# Welcome to Python - Study Notes

## Basic Output
The `print()` function is used to display output on the console.

```python
# Single argument
print("Hello World")

# Multiple arguments (comma-separated)
print("A", "B", "C")
```

## Comments
Use the `#` symbol for single-line comments.
```python
# This is a comment
```

## Strings
Python supports single, double, and triple quotes for strings.
```python
'Single quotes'
"Double quotes"
"""Triple quotes for 
multi-line strings"""
```

## Print Parameters
- `sep`: Specifies the separator between multiple arguments (default is a space).
- `end`: Specifies what to print at the end (default is a newline `\n`).

```python
print("A", "B", "C", sep="---") # Output: A---B---C
print("Hello", end=" ")
print("World") # Output: Hello World (on the same line)
```

## Basic Arithmetic in Print
The `print()` function can evaluate expressions.
```python
print(5 + 3) # Addition
print(10 - 2) # Subtraction
print(4 * 2) # Multiplication
print(9 / 3) # Floating-point division
print(9 // 3) # Floor division
print(9 % 2) # Modulo
print(2 ** 3) # Exponentiation
```
