# Setup and Installation - Study Notes

## Environment Setup
- **Python Installation**: Download and install the latest version of Python from [python.org](https://www.python.org/).
- **IDE**: Visual Studio Code (recommended) with the Python extension.

## Verification
To check if Python is installed, run:
```bash
python3 --version
```

## Running Your First Script
Create a file named `hello_world.py`:
```python
print("Hello World!")
```
Run it using:
```bash
python3 hello_world.py
```
